# Prototipo · tema nube

Prototipo visual de CloudSpace con el tema nube (cielo de noche, negro y día nublado), navegación de PC y barra inferior del móvil, asistente paso a paso para añadir datos y todas las secciones (Resumen, Tareas, Hábitos, Tiempo, Diario, Finanzas, Plan, Estudios y Ajustes).

- Es un archivo HTML único, sin dependencias: se abre en `/prototipo/`.
- Usa **datos de ejemplo** y no se conecta a Supabase: nada de lo que hagas aquí se guarda ni toca la app real.
- Atajo de PC: pulsa **A** dos veces rápido para ir al apartado anterior y **B** dos veces para el siguiente (no funciona mientras escribes).
